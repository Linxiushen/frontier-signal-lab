# ReWY: reduce the derivative graph before measuring its implementation

The new signal is an [upstream integration RFC](https://github.com/fla-org/flash-linear-attention/issues/1653), posted by `ZhangYi2026` on 2026-11-03 at 09:16:16 UTC. It links the [November 1 ReWY preprint](https://arxiv.org/abs/2611.01940) and a public MIT implementation. This is a new proposal to FLA and our first review of an older preprint; it is not an accepted upstream change or a new result measured here. We pinned the implementation at [`40777dca`](https://github.com/flashserve/ReWY/tree/40777dca852a9bb943d3eed9a0ce4188eff46d38). The RFC account identifies its team as the paper's authors; the manuscript and software citation list the same six names. We infer no employment or unpublished research direction from that attribution.

The actual caller is an existing chunkwise DeltaNet/GDN/KDA/GDN2 training backward. The proposal changes its local derivative computation while retaining the recurrent model and objective. In the paper's notation, the chunk correction satisfies `M R = Z - E S`, where `M = I + L` is unit lower triangular. Given the accumulated correction adjoint, one shared sensitivity `P = M^{-T} bar(R)` supplies the value gradient, the direct erase-factor gradient `-P S^T`, and the strict-causal coefficient gradient `-lower(P R^T)`. The downstream interaction contractions and reverse state scan still run. The incoming-state term must be accounted for once.

This explains the reported seven-to-three matrix-product reduction: the expanded reference graph differentiates transformed keys and a triangular inverse separately; the residual formulation eliminates their auxiliary adjoints. It applies the known derivative of a linear solve to this composite operator. The authors explicitly do not claim a new general differentiation rule or that every other implementation executes seven products. Their local FLOP calculation excludes the common state scan, interaction products and recomputation. It cannot predict a complete backward or training-step speedup.

The main engineering tradeoff is the lifetime of `P` and the coefficient adjoint. Reusing them can remove arithmetic while adding storage or extending register lifetimes; separating consumers exchanges memory traffic for shorter live ranges. The captured scalar producer/consumer source shows the shared sensitivity, strict causal masking and separate scalar reductions. Its use of dtype conversions also makes the exact-arithmetic result distinct from floating-point trajectory equivalence. We did not compile or execute this code.

The [public integration](https://github.com/flashserve/ReWY/blob/40777dca852a9bb943d3eed9a0ce4188eff46d38/src/fast_delta_rule/integrations/fla.py) uses FLA's backend registry for KDA/GDN and explicit aliases for DeltaNet/GDN2. The architecture documentation describes private backward bindings that retain the selected backward after leaving a backend context. This provides a concrete future integration and rollback point. It also has a version boundary: the documented release targets Linux and FLA `a59bc5df8c5841dce2169bb00e4027287197ba77`, rather than whichever FLA commit is current. The release envelope is fixed-length BF16 batches, chunk size 64, equal head counts, `K=V=128` and positive sequence lengths divisible by 64. Packed inputs, context parallelism, concurrent host threads, distributed training and full-model convergence are outside its validated envelope. The captured runtime checks manifested FLA source hashes and input capabilities, defaults to refusal and offers explicit original-backend fallback for rejected capabilities; it does not catch arbitrary kernel failures. This is source evidence, not local validation of those paths.

The performance numbers remain author measurements. The paper reports 1.18–1.70× geometric-mean complete low-level backward gains on H100/H200 across four operators and matched saving policies. These combined implementations include complementary matrix-intra or Gram-elimination work and scheduling changes. They are not isolated residual-WY effects. That timing boundary includes recomputation but excludes the public wrapper's final gradient conversion. The Ascend 950 public-autograd timings include conversion and allocation and must remain a separate cohort. Historical dagger-marked cohorts that lowered existing FP32 matrices stay excluded from precision-qualified claims even when tolerance checks pass. The plots also state a positive-aggregate display policy, so a visible bar is not an unbiased summary of every explored configuration.

Full-model evidence has another boundary. The reported model interval is `loss.backward()` on randomly initialized models and resident synthetic tokens; forward/loss, optimizer work, data loading and initialization are outside the interval. The H100/H200 fixed-architecture KDA groups report +9.93%/+8.83% backward execution-rate gains, with smaller gains in the other highlighted groups. GDN2 is an identified FLA layer port with official dimensions. Other families retain performance-only diagnostics; ten of eleven DeltaNet configurations per card fail the generic trajectory diagnostic. Operator gradient checks and finite execution therefore cannot establish model training equivalence, convergence or quality. Author memory measurements are incremental backward peak allocation, with some resident workspace separately reported, not total model peak memory.

For our H1 work, this adds a concrete alternative explanation for lower training cost: remove redundant derivative work while holding the model and saving policy fixed. It does not support residual-bank quality or rescue the failed v4 freeze, its negative saved-data comparisons, invalid historical RSS endpoint or original resource gates. No new H1–H4 experiment ran. A future admissible study needs an available supported accelerator, a pinned native model/backend and an independently frozen protocol: identical workload, initialization and saving policy; actual optimized-backward counters and explicit fallback; every supported gradient and quality endpoint; matched complete training cost, useful throughput and tail latency; appropriate total-memory/resource endpoints and observation cost. It must separately measure residual-only and companion changes when attributing effects. This is a proposed integration gate, not a registered or executed experiment, and acquiring paid hardware is not an exit condition.
